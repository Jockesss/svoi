# Картинки, аудио и видео для игры

```
media/
├── round1/            ← Раунд 1
│   ├── theme1/        ← тема 1 (первая строка табло)
│   ├── ...
│   └── theme7/
├── round2/  (theme1 … theme7)
├── round3/  (theme1 … theme7)
├── final/             ← финальные вопросы
├── sounds/            ← свои звуки (например, wrong.mp3)
└── demo/              ← примеры из шаблона, можно удалить
```

## Как называть файлы

Удобно называть по стоимости вопроса:

| Файл | Что это |
|---|---|
| `round1/theme2/300.jpg` | картинка к вопросу за 300 |
| `round1/theme2/300-answer.jpg` | картинка к ответу |
| `round2/theme5/800.mp3` | аудио к вопросу (угадай мелодию) |
| `final/3.jpg` | картинка к 3-й финальной теме |

И пропишите путь в `game.json` (без `media/` в начале):

```json
{ "value": 300, "text": "Кто на фото?", "image": "round1/theme2/300.jpg",
  "answer": "Вася", "answerImage": "round1/theme2/300-answer.jpg" }
```

Форматы: jpg, png, gif, webp, svg, mp3, mp4.
Если путь указан неверно, сервер при запуске напишет, какого файла не хватает.

## Свой звук неправильного ответа

По умолчанию играет встроенный гудок. Чтобы поставить свой, положите файл в `sounds/`
и укажите в `game.json`: `"settings": { ..., "wrongSound": "sounds/wrong.mp3" }`.
