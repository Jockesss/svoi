# Своя игра — табло для вечеринки

Табло в стиле «Своей игры» на 7 игроков: 3 раунда с темами и стоимостью, «Кот в мешке», «Аукцион», таймер и финал со ставками.

## Запуск

```bash
go run .
# или собрать один бинарник:
go build -o svoi . && ./svoi
```

Откройте http://localhost:8080 и нажмите ⛶, чтобы развернуть на весь экран (удобно на телевизоре через HDMI).
Сервер также печатает адрес в локальной сети: с ним можно открыть табло с другого устройства.

Флаги: `-addr :8080`, `-game game.json`, `-media media`, `-state state.json`.

## Как вести игру

| Действие | Как |
|---|---|
| Кто выбирает вопрос | клик по имени игрока внизу (подсвечивается золотом) |
| Переименовать игрока | двойной клик по имени |
| Поправить счёт | кнопки ±, или клик по числу и ввод вручную |
| Открыть вопрос | клик по ячейке |
| Засчитать ответ | ✓ (плюс стоимость, игрок становится выбирающим) или ✗ (минус стоимость, можно отвечать следующему) |
| Показать ответ / вернуться к табло | **Пробел** |
| Таймер пауза/старт | **T** |
| Ошиблись | **↶ Отменить** или **Ctrl+Z** (отменяет по одному действию) |
| Перейти к раунду / финалу, сбросить игру | меню ☰ |

Прогресс сохраняется в `state.json` после каждого действия. Если случайно закрыли вкладку, просто откройте её заново.
Новая игра: меню ☰ → «Сбросить игру» (или удалить `state.json`).

**«Кот в мешке»:** после заставки кликните, кому отдали вопрос. Отвечает только он.
**«Аукцион»:** введите выигравшую ставку и кликните по победителю торгов. ✓/✗ даёт ± ставку.
**Финал:** клики по темам убирают их, пока не останется одна. Затем ведущий вводит ставки (на экране они скрыты), показывает вопрос и ответ, отмечает ✓/✗ каждому и подводит итоги.

## Вопросы: `game.json`

`game.json` перечитывается при каждом обновлении страницы, так что правки видны сразу, без перезапуска.
Если в файле ошибка, страница покажет, где именно.

```jsonc
{
  "title": "Своя игра · ДР",
  "players": ["Аня", "Боря", "..."],          // 7 имён
  "settings": {
    "timer": 20,            // секунд на вопрос (-1 — без таймера)
    "finalTimer": 60,
    "autoStartTimer": true,
    "wrongSound": ""      // свой звук ошибки, например "sounds/wrong.mp3"
  },
  "rounds": [
    {
      "name": "Раунд 1",
      "themes": [
        {
          "name": "Кино",
          "questions": [
            { "value": 100, "text": "Вопрос текстом", "answer": "Ответ" },
            { "value": 200, "text": "Что за фильм?", "image": "round1/theme1/200.jpg", "answer": "Титаник" },
            { "value": 300, "text": "Чей это голос?", "audio": "round1/theme1/300.mp3", "answer": "...", "answerImage": "round1/theme1/300-answer.jpg" },
            { "value": 400, "type": "cat", "catTheme": "Мультики", "text": "...", "answer": "..." },
            { "value": 500, "type": "auction", "text": "...", "answer": "..." }
          ]
        }
      ]
    }
  ],
  "final": {
    "themes": [
      { "name": "Финальная тема", "text": "Вопрос", "image": "final/1.jpg", "answer": "Ответ" }
    ]
  }
}
```

Поля вопроса:
- `value`: стоимость (обязательно).
- `text`, `image`, `audio`, `video`: что показать. Нужно хотя бы одно, можно сочетать.
- `answer`, `answerImage`: ответ текстом и/или картинкой. Нужно хотя бы одно.
- `type`: `"cat"` («Кот в мешке», можно добавить `catTheme`) или `"auction"`.

Картинки, аудио и видео кладите в папку `media/`. Под каждый раунд и тему уже есть папки:
`media/round1/theme1` … `media/round3/theme7` и `media/final`. Как называть файлы, написано в [media/README.md](media/README.md).
Пример: `media/round1/theme2/300.jpg` → `"image": "round1/theme2/300.jpg"`.
Подходят jpg, png, gif, webp, svg, mp3, mp4. Если файла нет, сервер напишет предупреждение при запуске.

**Звук неправильного ответа:** при ✗ играет встроенный гудок. Свой звук: положите файл в `media/sounds/`
и укажите `"wrongSound": "sounds/wrong.mp3"` в `settings`.
